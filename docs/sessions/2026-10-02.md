# Сессия 2026-10-02 — редизайн tapreply.net

Ветка: `redesign-2026-10` (от `main` @ `b520bc0`). Локальные коммиты, **без push**, без деплоя.

## Что сделано

- Одностраничник заменён многостраничным статическим сайтом на **Astro 7.3 + TypeScript** (Node 24 через nvm, `.nvmrc`). Старый `index.html` → `legacy/index.html`, `CNAME` → `public/CNAME`.
- **3 языка**: EN (`/`), RU (`/ru/`), ES (`/es/`), переключатель языка в шапке (ведёт на ту же страницу).
- **Страницы** (на каждом языке): главная, `/features/`, `/how-it-works/`, `/pricing/`, `/pilot/`, `/faq/`, `/about/`, `/privacy/`, `/terms/` (черновики), сегментные `/for/restaurants/`, `/for/hotels/`, локализованная 404.
- **Главная**: hero с HTML/CSS-мокапом телефона (4 шага «Туристического щита» сменяются CSS-анимацией, при reduced-motion — статично), площадки с честной легендой (API готовится / письма-уведомления / вручную), «Как это работает» в 3 шага, демо щита, «Почему TapReply», честное сравнение с подсказками Google, светлая секция «Безопасность», тарифы, FAQ, CTA.
- **Пилот**: кому подходит / что получаете / что просим, форма-заявка → открывает почтовый клиент с предзаполненной темой и телом (`ceo@ankosoftlab.com`), разметка готова под будущий обработчик (`data-endpoint`).
- **Бренд**: из `tr_logo.png` скриптом `scripts/build-brand.mjs` сделаны logo webp/png, apple-touch-icon, favicon 16/32/ico, og-image 1200×630. `favicon.svg` — временный вектор.
- **SEO**: уникальные title/description, canonical, hreflang (en/ru/es/x-default), OG + Twitter card, JSON-LD (Organization, WebSite, SoftwareApplication с offers; FAQPage на /faq), sitemap с i18n-альтернативами, robots.txt, web manifest, theme-color.
- **Cloudflare Pages**: `public/_headers` (immutable-кэш ассетов, security-заголовки, CSP **без unsafe-inline**), `public/_redirects`.
- **Качество**: 0 inline-скриптов/стилей, JS — один файл формы (~1.5 КБ) только на /pilot; один CSS (~40 КБ); шрифт Inter self-hosted (latin + cyrillic), preload, `font-display: swap`.
