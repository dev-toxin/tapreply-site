# Decisions — tapreply-site

Формат: дата · решение · почему · альтернативы. Все решения ниже приняты 2026-10-02 автономно (владелец недоступен) и могут быть пересмотрены.

## 2026-10-02 · Стек: Astro 7 + TypeScript, чистый CSS с токенами
- **Решение:** Astro 7.3 (последняя стабильная на дату), `output: static`, TypeScript strict, без Tailwind — CSS custom properties + scoped `<style>` компонентов.
- **Почему:** через nvm доступен Node 24 (правило стека → Astro). Нулевой JS по умолчанию, встроенная i18n, `@astrojs/sitemap`. Чистый CSS — меньше зависимостей, токены 1:1 из `tapreply-monorepo/docs/design-system.md`, легко читать.
- **Альтернативы:** Hugo (запасной вариант, не понадобился); Tailwind (лишний слой для сайта из ~10 шаблонов).
- Зависимостей всего две: `astro`, `@astrojs/sitemap`. `.nvmrc = 24`, `engines.node >= 20`.

## 2026-10-02 · Старый index.html → legacy/index.html
- Сохранён для истории (`git mv`, история файла не теряется). В сборку не попадает.
- `CNAME` перенесён в `public/CNAME` → копируется в `dist/` (на случай GitHub Pages).

## 2026-10-02 · Языки: EN (/, по умолчанию), RU (/ru/), ES (/es/)
- RU — первый рынок (русскоязычные владельцы в Грузии и Казахстане); ES — следующий (Испания, Латам); EN — международный и x-default.
- Тексты лежат в `src/i18n/{en,ru,es}.ts`; тип `Dict` выводится из `en.ts`, поэтому TypeScript требует, чтобы ru/es имели ту же структуру.
- **ES нужно вычитать носителю** (написан как естественный castellano, обращение на «tú», но без проверки носителем).
- ka/kk не делались (нет носителей, машинный перевод запрещён) — см. вопросы в сессии.
- Маршруты: один файл на страницу `src/pages/[...lang]/<page>.astro` + `getStaticPaths` по всем языкам. URL с завершающим слэшем (`trailingSlash: 'always'`).

## 2026-10-02 · Цены — гипотеза
- Free — 1 заведение, 5 AI-ответов/мес; Pilot/Individual — ориентир $19–29/мес за заведение; Multi (3–5) — скидка за точку; Chain — по запросу.
- **Это гипотеза для проверки спроса**, не утверждённая цена (в продуктовом v1-scope цены явно не зафиксированы до расчёта unit-экономики). На сайте везде плашка «тарифы раннего доступа, могут измениться». Оплата пилота — инвойс, без автосписаний.
- В JSON-LD указаны только Free ($0) и диапазон $19–29, без рейтингов/отзывов.

## 2026-10-02 · Честность про площадки
- Google — «официальный API (готовится)». Остальные — пересылка писем-уведомлений и/или «вставить/поделиться» + ручная вставка ответа. Facebook и «любой сайт» — только вручную.
- Нигде не обещаем «входим в ваш аккаунт»; отсутствие паролей подано как преимущество (безопасность).
- Логотипы площадок не используем — только текстовые бейджи (товарные знаки).
- Без соцдоказательства: нет отзывов клиентов, логотипов «нам доверяют», цифр клиентов. Демо щита — вымышленное заведение с пометкой «Пример».
- AI-провайдеры не называются.

## 2026-10-02 · Дизайн
- Тёмная тема по умолчанию (токены продукта: `#121214`, `#1A1A1E`, `#FF6B00`, `#FFFFFF`, `#B8B8C4`). Одна светлая секция-контраст — «Безопасность» на главной. Поддержку `prefers-color-scheme: light` не делал (одна тема = меньше поверхность для ошибок; бэклог).
- Оранжевый для мелкого текста — `#FF9D3D` (≈8.6:1 на `#121214`); `#FF6B00` — только фон кнопок (текст на нём тёмный `#121214`, ≈6.9:1) и декоративные элементы. На светлой секции — `#B44A00`.
- Hero-мокап — HTML/CSS, 4 шага «Туристического щита» переключаются CSS-анимацией (только opacity/transform); при `prefers-reduced-motion` — статичный список всех 4 блоков.
- Иконки — собственные inline SVG 24×24, stroke 1.5.
- Мобильная навигация — `<details>` без JS.

## 2026-10-02 · Шрифт
- Inter Variable (OFL 1.1), self-hosted, два сабсета woff2: latin (48 КБ) и cyrillic (19 КБ), `font-display: swap`, preload latin (+cyrillic на /ru/). Взято из npm-пакета `@fontsource-variable/inter@5.3.0` разово (`npm pack`), в зависимости не добавлен. Лицензия — `public/fonts/OFL-Inter.txt`.
- Google Fonts CDN не используется (GDPR, скорость).

## 2026-10-02 · Логотип и иконки
- Источник — `/Users/tokc/Desktop/AnKo Software Labs/tr_logo.png` (2048², без прозрачности, графитовый фон). Оригинал в репозиторий не кладём (4 МБ).
- Скрипт `scripts/build-brand.mjs` (sharp, уже есть в зависимостях Astro) вырезает знак (круговая стрелка + жест тапа) и делает: `brand/logo-512.webp`, `brand/logo-96.webp` (скруглённая плашка), `brand/logo-192.png`, `brand/logo-512.png`, `apple-touch-icon.png` 180², `favicon-32.png`, `favicon-16.png`, `favicon.ico` (16/32/48), `og-image.png` 1200×630 (знак + слоган на `#121214`).

- Версии с прозрачностью из `logo/` и `archive/` содержат водяной знак генератора («HIGGSFIELD AI») или другой вариант знака (пузырь/искры) — не использованы. **Нужен финальный вектор.**
- `public/favicon.svg` — **временный** простой вектор (незамкнутая круговая стрелка + точка-тап). Заменить финальным векторным знаком.

## 2026-10-02 · Форма пилота без бэкенда
- `<form action="mailto:…" enctype="text/plain">` — работает даже без JS. С JS (`public/scripts/pilot-form.js`, внешний файл ради CSP) собирается читаемое письмо с предзаполненной темой и телом и открывается почтовый клиент.
- Для будущего обработчика: заполнить `data-endpoint` и `action`/`method` (Cloudflare Pages Function или Formspree). Никакие сервисы форм не регистрировались.

## 2026-10-02 · Хостинг и заголовки (Cloudflare Pages, не задеплоено)
- `public/_headers`: `immutable` кэш для `/_astro/*` и `/fonts/*`; X-Content-Type-Options, Referrer-Policy, Permissions-Policy, X-Frame-Options, COOP, HSTS (без preload).
- **CSP без `unsafe-inline`**: `script-src 'self'; style-src 'self'`. Это реально, потому что: `build.inlineStylesheets: 'never'`, `assetsInlineLimit: 0`, единственный JS — внешний файл, JSON-LD (`application/ld+json`) не исполняется и CSP его не блокирует. `scripts/check-links.mjs` проверяет, что в HTML нет inline `<script>` и `style=""`. `img-src` допускает `data:` (SVG-галочка в CSS).
- `public/_redirects`: `/en/*` → `/`, пара удобных коротких адресов. www↔apex не настраиваем (DNS / правила Cloudflare).
- Локализованные 404: `/ru/404.html`, `/es/404.html` (Cloudflare Pages берёт ближайший 404.html вверх по пути). Небольшая интеграция в `astro.config.mjs` переносит их из `ru/404/index.html`.
- CSS собирается в один файл (`cssCodeSplit: false`, ~39 КБ): один кэшируемый запрос на весь сайт.
